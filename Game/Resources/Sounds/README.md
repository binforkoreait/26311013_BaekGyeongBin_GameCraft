# 합성 효과음

2026-10-26 제작. 외부 음원을 사용하지 않고 정현파를 순서대로 재생하면서 각 음에 감쇠를 적용했다. 22050Hz, mono, signed 16-bit PCM WAV 형식이다.

| 파일 | 길이 | 음높이(Hz) | 용도 |
|---|---|---|---|
| start.wav | 0.36초 | 440, 660, 880 | 시작 알림 |
| shot.wav | 0.10초 | 900, 220 | 발사 임시 효과음 |
| hit.wav | 0.18초 | 180, 90 | 피격 임시 효과음 |
| wave.wav | 0.50초 | 523, 659, 784, 1046 | 웨이브 전환 |

각 파일의 음높이는 같은 길이로 분할한다. 최대 진폭은 7000/32767이며 각 구간에서 선형으로 감쇠한다. 이번 프로토타입은 start.wav만 재생한다. 나머지는 후속 전투 구현에 사용할 자료다.
