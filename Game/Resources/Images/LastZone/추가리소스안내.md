# 추가 리소스 사용 안내

제작일: 2026-10-26. 내장 image_gen 도구로 생성. 두 파일 모두 실제 크기 1254×1254, RGBA이며 알파 범위 0~255를 확인했다.

## combat_effects_v1.png

4열 × 4행 전투 효과 시트. 위에서부터 총구 섬광 / 탄착 불꽃 / 좀비 소멸 연기 / 등장 연기다. 각 행은 왼쪽에서 오른쪽으로 4프레임을 한 번 재생한다. 시작 속도는 초당 12~16프레임으로 시험한다.

셀 경계는 가로·세로 모두 [0,314,627,941,1254]를 사용한다. 생성 결과의 일부 입자는 셀 경계 가까이에 있어, 실제 재생 시 잘림과 흔들림을 확인해야 한다. 총구 섬광은 총구 위치, 탄착은 충돌 위치, 연기는 적 중심에 배치하고 표시 크기를 각각 조정한다.

## hud_icons_v1.png

윗줄 왼쪽부터: 체력 있음 / 체력 없음 / 총알 / 조준점.
아랫줄 왼쪽부터: 처치 수용 해골 / 일시정지 / 재시작 / 경고.

이 파일은 아이콘 소재 모음이다. 이미지 상단·하단 여백과 아이콘 간격이 일정하지 않으므로 4×2 동일 셀 시트로 그대로 재생하지 않는다. 각 아이콘의 불투명 영역에 맞춰 소스 사각형을 지정한다. 원본을 보존하고 실제 화면에서 아이콘 표시 크기를 맞춘다.

전투 효과와 아이콘은 아직 C++ 로딩 코드에 연결하지 않았다. 사운드 및 위·아래 방향 캐릭터 프레임은 이번 추가 묶음에 포함되지 않는다.

## 실제 생성 프롬프트

### 전투 효과

Use case: stylized-concept. Asset type: transparent combat effects sprite atlas for LAST ZONE pixel art zombie shooter. Exactly 4 columns by 4 rows in a square PNG with actual transparent background, evenly spaced equal cells, no grid lines or labels. Cohesive crisp pixel art, dark outlines where appropriate, readable when small. Row 1: four consecutive animation frames of rightward pistol muzzle flash, yellow-white core orange edge, grows then fades. Row 2: four consecutive frames of small bullet impact spark, yellow and warm white, expands then fades. Row 3: four consecutive frames of zombie defeat disappearance effect, muted green-gray vapor and small particles, non-graphic, expands and disperses. Row 4: four consecutive frames of enemy spawn effect, subtle violet-gray circular puff with glowing center, gathers then disperses. Each effect centered on the exact center of its equal cell, fully inside central 65 percent with transparent gutters. No guns, characters, backgrounds, floor, text, watermark, UI, blood or gore. Distinct visual progression across each row, production game VFX sprite sheet.

### UI 아이콘

Use case: stylized-concept. Asset type: transparent pixel art HUD icon atlas for LAST ZONE zombie shooter. Square PNG actual transparent background, precise 4 columns x 2 rows evenly sized cells, each icon isolated and centered with generous gutters. Crisp hand placed pixel art look, dark charcoal outlines, strong readability at small scale, worn urban arcade style. Top row from left to right: full bright red heart, empty dark gray heart with red outline, compact brass pistol bullet oriented right, white aiming crosshair with four short cardinal strokes and hollow center. Bottom row left to right: small white skull, pause symbol two pale ivory vertical bars, clockwise restart arrow in pale ivory, round yellow warning icon with dark exclamation mark. No words, no captions, no grid lines, no background panels, no extra decorative objects, no watermark. Identical apparent icon scale, each within central 55 percent of cell. Game usable HUD sprites rather than presentation mockup.
