# LAST ZONE - 라스트 존

C++ / glc2d로 제작하는 탑다운 좀비 슈팅 게임. 작성자: 26311013 백경빈.

현재는 **2주차 이동 프로토타입**이다. 배경·플레이어·좀비 3종, 걷기 애니메이션, 플레이어 이동과 적 추적, 일시정지·초기화, 시작 효과음을 포함한다. 사격·피해·웨이브는 후속 단계에서 구현한다.

## 실행

Visual Studio 2022에서 [Game.sln](Game/Game.sln)을 열고 NuGet 패키지를 복원한 뒤 **Debug / x64**로 빌드한다. Ctrl+F5로 실행하면 바로 게임이 시작된다. 제목과 설명문은 표시하지 않는다.

- WASD: 이동
- 마우스: 좌우 바라보는 방향 및 조준점
- Esc: 일시정지 / 재개
- R: 진행 중 객체 초기화

빌드 결과는 Game/_bin/x64/Debug에 저장되고 필요한 이미지·사운드는 자동 복사된다.

이 PC의 Visual Studio 디버그 정보 도구 오류를 피하기 위해 실행 파일용 디버그 심볼 생성은 기본적으로 꺼져 있다. 실행에는 지장이 없으며 중단점 디버깅 제한과 복원 방법은 2주차 개발 현황 문서에 기록했다.
